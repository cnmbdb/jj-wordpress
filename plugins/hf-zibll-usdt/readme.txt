=== HF 子比 USDT 收款 ===
Contributors: cnmbdb
Requires PHP: 7.4
Stable tag: 1.0.0

独立 WordPress 插件，向子比主题收款设置与结账流程注入 USDT 支付。

== Description ==
易支付桥接已实现；epusdt、TokenPay 为待接入选项。默认关闭，所有商户参数由站长填写。
不包含生产配置、商户凭据、订单、数据库或主题代码。tests 中均为虚构测试数据。

== Installation ==
上传 dist/hf-zibll-usdt-1.0.0.zip 并启用，在子比主题设置的收款接口中配置 USDT 易支付。
详细说明见 README.md。

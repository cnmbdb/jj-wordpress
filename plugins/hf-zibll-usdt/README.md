# HF 子比 USDT 收款

独立 WordPress 插件，适用于具有 `zibpay_payment_methods`、`zibpay_initiate_paysdk` 和 Codestar 收款设置过滤器的子比主题及其子主题。无需修改主题文件。当前在本仓库子比主题 API 上开发。

安装 ZIP 后启用插件，在「子比主题设置 → 支付&付费 → 收款接口」开启 USDT，选择易支付，填写 HTTPS 网关地址、商户 PID 和密钥并保存。商户必须已启用 usdt 通道。默认关闭，配置完整后结账才显示 USDT。epusdt、TokenPay 暂为待接入选项，不会显示不可用支付入口。

金额保持人民币，网关决定 USDT 汇率、网络及收款地址。插件使用易支付 MD5 协议提交到 submit.php。回调核对签名、PID、订单、支付类型、成功状态和提交金额，调用子比原生订单结算。已完成订单的相同交易重复通知返回 success。关闭开关仍可接收已有订单通知；停用插件则无法接收。支付记录保存 30 天，期间勿变更商户 PID 或密钥。

插件没有接管原路退款；USDT 退款需要在网关核实后处理。金额显示与订单明细仍使用子比本地货币。暂不提供 USDT 的原生订单明细图标扩展（父主题该函数未提供过滤器）。

验证：`php wp-content/plugins/hf-zibll-usdt/tests/run.php`。这些测试覆盖设置注入、开关与配置、提交签名和 HTML 转义、签名/金额/PID/类型篡改拒绝、重复回调，以及关闭开关后已有订单通知。上线前还需真实 WordPress 结账与网关小额付款确认。
